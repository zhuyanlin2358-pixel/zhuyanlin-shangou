2
提交审核
把HTML文件发给朱彦霖，附带以下信息：
• 组件ID（英文，如my-component）
• 组件名称（中文，如"我的动效组件"）
• 画布尺寸（如750×424）
• 配置项列表（如bgColor, title等）
3
上线使用
朱彦霖审核通过后，会手动放入 public/components/ 并注册到 registry.json。
组件上线后，你可以在闪购工具的「组件库」中看到并使用它。

SG_* 消息协议

这是工具与你的组件通信的标准协议。所有消息都通过 window.postMessage 发送。

工具发给你的消息（你必须接收）

消息类型 payload 说明
SG_CONFIG { bgColor, title, ... } 更新组件配置，你需要根据新配置重绘
SG_EXPORT { format: 'png' } 触发导出，你需要返回PNG图片
SG_PREVIEW { readOnly: true } 预览模式，组件只读展示

你发给工具的消息（你必须发送）

消息类型 payload 说明
SG_EXPORT_RESULT { dataURL, componentId } 导出结果，dataURL是base64 PNG
SG_READY { meta: {name, id, width, height} } 组件加载完成通知（可选）

代码示例：接收配置

JavaScript
window.addEventListener('message', (e) => {
  const { type, payload } = e.data;

  if (type === 'SG_CONFIG') {
    // 更新配置并重绘
    config = { ...config, ...payload };
    draw();
  }

  if (type === 'SG_EXPORT') {
    // 导出PNG
    const canvas = document.getElementById('canvas');
    const dataURL = canvas.toDataURL('image/png');

    window.parent.postMessage({
      type: 'SG_EXPORT_RESULT',
      payload: { dataURL, componentId: 'your-id' }
    }, '*');
  }
});

<script>
// ── 当前配置（工具会通过 SG_CONFIG 消息更新）──────────
let config = {
  bgColor: '#FFCCCC',
  title: '默认标题',
  titleColor: '#1A1A1A',
}

// ── 绘制函数（核心逻辑写在这里）──────────────────────────
function draw() {
  const canvas = document.getElementById('canvas');
  const ctx = canvas.getContext('2d');

  // 清空画布
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  // 绘制背景
  ctx.fillStyle = config.bgColor;
  ctx.fillRect(0, 0, canvas.width, canvas.height);

  // 绘制标题
  ctx.fillStyle = config.titleColor;
  ctx.font = 'bold 120px sans-serif';
  ctx.textAlign = 'center';
  ctx.textBaseline = 'middle';
  ctx.fillText(config.title, 750, 424);
}

// ── 导出 PNG（不要改这个函数）─────────────────────────────
function exportPNG() {
  return document.getElementById('canvas').toDataURL('image/png');
}

// ── 监听工具消息（不要改这段）────────────────────────────
window.addEventListener('message', (e) => {
  const { type, payload } = e.data || {};

  if (type === 'SG_CONFIG') {
    config = { ...config, ...payload };
    draw();
  }

  if (type === 'SG_EXPORT') {
    const dataURL = exportPNG();
    window.parent.postMessage({
      type: 'SG_EXPORT_RESULT',
      payload: { dataURL, componentId: 'your-comp-id' }
    }, '*');
  }
});

// ── 初始绘制 ──
draw();
</script>

动效组件规范

动效组件（如粒子、动画）需要自行实现动画逻辑。
遵循以下规范，确保能正确接入工具。

界面布局规范

区域宽度内容
左侧配置面板260-300px预设选择、参数调节
右侧预览区剩余空间Canvas画布、实时预览
顶部工具栏100%组件名称、导出按钮

组件接入规范

双模式支持
// 通过URL参数判断模式
const urlParams = new URLSearchParams(window.location.search);
const mode = urlParams.get('mode') || 'preview'; // 'studio' | 'preview'

if (mode === 'studio') {
  // 编辑模式：显示完整UI（左侧面板+右侧预览）
  showConfigPanel();
  showPreviewArea();
} else {
  // 预览模式：只显示结果（用于会场画布）
  hideConfigPanel();
  showPreviewOnly();
}

静态规范

项目规范
画布尺寸750×424（头图）或 750×242（卡片）

导出格式canvas.toDataURL('image/png')
背景透明或按配置bgColor绘制

动态规范（动画）

动画实现建议
// 方案1：使用GSAP（推荐）
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/gsap.min.js"></script>
<script>
  gsap.to(element, { x: 100, duration: 2, repeat: -1 });
</script>

// 方案2：使用requestAnimationFrame
function animate() {
  updateParticles(); // 更新粒子位置
  draw();            // 重绘画布
  requestAnimationFrame(animate);
}
animate();

// 方案3：使用CSS动画（仅非Canvas元素）
element.style.animation = 'slide 2s infinite';
